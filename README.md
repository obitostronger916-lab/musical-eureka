# Universal Media

Universal Media — Telegram uchun ko‘p tilli media va musiqa yordamchisi.

## Holat

Loyiha ishlab chiqish bosqichida. Bot hozircha ishga tushirilmagan.

## Rejalashtirilgan imkoniyatlar

- O‘zbek, rus va ingliz tillari
- Telegram shaxsiy va guruh chatlari
- Ommaviy va ruxsat etilgan media havolalarini aniqlash
- Musiqa nomi yoki ijrochi bo‘yicha qidirish
- Audio, ovozli xabar va video orqali musiqa aniqlash imkoniyatini bosqichma-bosqich qo‘shish
- Administrator boshqaruvi va xavfsizlik cheklovlari

## Texnologiyalar

Python, aiogram 3, FastAPI va PostgreSQL.

## Xavfsizlik

Bot tokeni va boshqa maxfiy qiymatlarni hech qachon GitHub'ga joylamang. Ularni hostingdagi Environment Variables orqali sozlang.
